# HoodWaffle

Vape-style click GUI script for Hood Customs — ESP, silent aim with velocity prediction + hit chance, camera aim, KO/grab-aware targeting, config save/load.

## Execute

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/vrcdev/HoodWaffle/main/loader.luau"))()
```

## Controls

- **Delete** — toggle menu
- **End** — unload
- Left-click module = toggle · Right-click = expand settings
